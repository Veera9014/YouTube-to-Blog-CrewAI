# YouTube to Blog Generator using CrewAI

An AI-powered application that converts YouTube videos
into structured blog articles.

## Features
- YouTube transcript extraction
- Multi-agent workflow using CrewAI
- Groq LLM integration
- Automated blog generation
- Markdown download

## Tech Stack
- Python
- Streamlit
- CrewAI
- Groq API
- YouTube Transcript API

## Run Locally
pip install -r requirements.txt
streamlit run app.py
